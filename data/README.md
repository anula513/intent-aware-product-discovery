# Data

Raw data is **not** in this repository. It is licensed by H&M for non-commercial use and academic research only, and may not be redistributed (Kaggle competition rules, section 7). Both `raw/` and `processed/` are gitignored.

## How to get it
1. Create a Kaggle account and open the competition **H&M Personalized Fashion Recommendations** (kaggle.com/competitions/h-and-m-personalized-fashion-recommendations).
2. Accept the competition rules (via "Late Submission").
3. From the **Data** tab, download these files into `data/raw/`:

| File | Size | Contents |
|------|------|----------|
| articles.csv | ~34 MB | product catalog (105,542 products) |
| customers.csv | ~198 MB | customer attributes |
| transactions_train.csv | ~3.25 GB | purchases (date, customer, article, scaled price, channel) |

The `images/` folder is not needed locally.

**Downloaded:** 2026-11-21 by Anula Dinesh, from the official competition page (not a re-upload).

## Folders
- `raw/`: files exactly as downloaded. Never edited.
- `processed/`: everything generated by code from `raw/` (Parquet caches, cleaned and split files). Can be deleted and rebuilt at any time.
